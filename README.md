# portfolio

Portfólio profissional — página única, sem framework, sem build.

**[matheus-mendes-dev.vercel.app](https://matheus-mendes-dev.vercel.app)**

## O que tem

- 13 projetos em cards com **a métrica que prova o resultado** (testes, AUC, registros, hit rate)
- filtro por categoria (IA, automação, backend) em JavaScript puro
- fontes servidas localmente (sem CDN, sem requisição externa)
- responsivo, sem dependência e sem etapa de build

## Por que assim

Recrutador abre o link no celular, muitas vezes em rede ruim. Uma página única, sem
`node_modules` e sem CDN, carrega em um round-trip e nunca aparece quebrada por um
script de terceiro que caiu.

## Atualizar

Editar `index.html`, copiar para cá e dar push. O deploy na Vercel é automático.
